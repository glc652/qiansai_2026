# 手腕端数据流

## 1. 总体链路

```text
手腕端传感器/健康模块
        ↓
底层总线与驱动
        ↓
心率、血氧、血压、HRV、微循环、疲劳等计算
        ↓
健康有效标志、序号、年龄和页面状态
        ↓
与上臂端/无线模块通信
        ↓
Web ingest_device_payload / APP API
        ↓
健康卡片、历史趋势和训练建议
```

## 2. 数据字段链

Web 侧能确认的健康字段为 `hv`、`hr`、`spo2`、`micro`、`fatigue`、`sbp`、`dbp`、`sdnn`、`rmssd`、`hseq`、`hage`。手腕端生成这些字段的原始传感器、采样和算法不属于手腕端文档以外的 Web 代码，需以 `F:\qiansai\U575` 源码实际函数为准。

## 3. 状态链

手腕健康界面进入/退出、健康请求、健康活动和数据有效标志会影响上臂端页面及 Web 自动切页。Web 侧对应别名为 `wh`、`whe`、`whexit`、`hreq`、`hv`；前端 `applyRealtime` 在数据新鲜时切换健康页，数据过期时回到首页或等待状态。

## 4. 缓存与可靠性

Web 侧按序号或时间组合去重，健康历史最多保存 500 条；APP 侧使用 IndexedDB 继续合并保存。健康数据新鲜度通常按 6500 ms 判断。具体手腕端重采样、滤波、异常剔除、蓝牙重连和低功耗策略【无法确认】。
