# AI-RehabBand 智能康复臂带 UI 设计方案

## 整体设计风格



| 序号 | 界面名称             | 是否推荐 | 说明                                     |
| ---- | -------------------- | -------- | ---------------------------------------- |
| ①    | 🏠 主界面（Home）     | ⭐⭐⭐⭐⭐    | 系统首页，进入各功能模块                 |
| ②    | 🎯 训练动作选择       | ⭐⭐⭐⭐⭐    | 用户选择训练项目（肘关节弯曲、肩上举等） |
| ③    | ⏳ 准备训练（倒计时） | ⭐⭐⭐⭐     | 校准 IMU，提示用户保持初始姿势           |
| ④    | 📈 实时训练界面       | ⭐⭐⭐⭐⭐    | 实时显示角度、评分、曲线、动作信息       |
| ⑤    | 🎉 训练完成界面       | ⭐⭐⭐⭐     | 展示综合评分和训练结果                   |
| ⑥    | 📚 历史记录           | ⭐⭐⭐      | 查看历史训练数据                         |
| ⑦    | 📊 数据统计           | ⭐⭐⭐⭐     | 展示趋势图、柱状图、康复分析             |
| ⑧    | ⚙️ 设置界面           | ⭐⭐⭐      | 调整亮度、语音、蓝牙等参数               |
| ⑨    | ⌚ 手腕端实时显示界面 | ⭐⭐⭐⭐⭐    | 显示实时角度、当前动作、电量等关键信息   |

- 设备：2.8 寸 TFT LCD 触摸屏（320×240）
- 风格：现代医疗科技风（Medical UI）
- 配色：蓝白配色（Medical Blue + White）
- 布局：极简扁平化设计、圆角卡片、轻阴影
- 用户群体：脑卒中患者、康复医生
- 设计参考：Apple Health、华为运动健康、医院医疗设备 UI

# 9. 手腕端（1.83 寸 LCD）实时界面

### 功能介绍

手腕端开机后默认进入首页，作为整个腕带的功能入口，不直接显示训练数据，而是提供两个主要功能模块，方便用户快速切换。

### 页面内容

- 顶部显示 **AI Rehab Band** 标题。
- 中央设置两个大尺寸圆角按钮：
  - 🏋️ **训练模式**
  - ❤️ **心率监测**
- 底部显示：
  - 蓝牙连接状态
  - 电池电量
  - 当前时间（可选）

### 设计目的

通过极简首页设计，使手腕端拥有类似智能手表的交互体验，同时突出康复训练与健康监测双功能。

### AI 图片生成提示词

设计一张智能康复腕带首页 UI，适用于 1.83 寸 LCD 屏幕，240*284现代医疗科技风，蓝白配色，极简扁平化设计。页面顶部显示 “AI Rehab Band” 标题，中间采用两个大型圆角功能卡片按钮：“🏋️ 训练模式”和“❤️ 心率监测”，按钮带有精美图标，底部显示蓝牙连接状态、电池图标和设备信息。整体风格参考 Apple Watch 和华为智能手表健康界面，简洁、高级、科技感强。

## 2. 训练界面（Training）

### 功能介绍

进入训练模式后，仅显示训练状态，不重复展示上臂端已经显示的角度、评分等复杂数据。

### 页面内容

- 顶部显示：
  - **训练中（Training）**
- 中央显示：
  - 康复训练图标或动态动画
  - “正在训练”文字
- 下方提示：
  - **请跟随上臂端完成训练动作**
  - **保持正确姿势**

### 设计目的

让用户专注于完成康复动作，小屏幕仅承担状态提示功能，提高可读性。

### AI 图片生成提示词

设计一张智能康复腕带训练界面，适用于 1.8 寸 LCD 小尺寸屏幕，现代医疗科技风，蓝白配色。顶部显示“训练中（Training）”，中央展示运动或康复训练图标及轻量动画，下方提示：请跟随上臂端完成训练动作，保持正确姿势

不显示复杂训练数据，仅突出训练状态，整体风格简洁、专业，类似智能手表运动模式界面。

## 3. 心率监测界面（Health Monitor）

### 功能介绍

实时显示用户的生命体征数据，实现健康监测功能。

### 页面内容

- ❤️ 心率（Heart Rate）
  - 示例：76 BPM
- 🩸 血氧饱和度（SpO₂）
  - 示例：98%
- 可选显示：
  - 心率动态波形
  - 心跳动画
  - 当前监测状态

### 设计目的

充分利用手腕佩戴位置，实现基础健康监测，增强产品实用价值。

### AI 图片生成提示词
