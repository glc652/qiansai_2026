本文档记录当前上臂端工程中三个已调试动作的判定方式和评估时的专门处理，涉及动作为：

- 屈肘：`ELBOW_FLEX`
- 前臂旋转：`FOREARM_ROT`
- 上臂外展：`ARM_ABD`

- 动作评估封装：`E:\qiansai\upper-arm\Core\Inc\rehab_eval.h`

## 2. 屈肘 ELBOW_FLEX

### 2.1 动作角度计算

屈肘使用上臂和腕端的 `pitch` 相对差值计算：

```c
relative_pitch = wrist_pitch - upper_pitch
flex = abs(relative_pitch - zero_relative_pitch)
```

最终得到：

```c
rehab_frame.elbow_angle_x100
```

即打印中的 `flex`。

### 2.2 动作分类判定

屈肘分类有两类触发条件。

保持角度触发：

```c
flex >= 30°
```

保持退出阈值：

```c
flex >= 30°
```

动态触发：

```c
elbow_range >= 25°
```

或：

```c
abs(elbow_velocity) >= 25°/s
```

也就是说，屈肘既可以通过达到一定弯曲角度识别，也可以通过短时间内明显的屈肘角度变化识别。

### 2.3 评估封装

屈肘评估封装为：

```c
ElbowFlexEval_DefaultConfig()
ElbowFlexEval_Init()
ElbowFlexEval_Start()
ElbowFlexEval_Update()
ElbowFlexEval_GetState()
ElbowFlexEval_Stop()
```

默认评估参数：

| 参数 | 当前值 |
|---|---:|
| 目标次数 | 5 次 |
| 进入阈值 | 30° |
| 退出阈值 | 30° |
| 目标角度 | 150° |

计数逻辑：

1. `flex >= enter_angle` 时进入一次动作。
2. 动作过程中记录本次峰值角度。
3. `flex <= exit_angle` 时完成一次。
4. 完成 5 次后评估结束。

### 2.4 屈肘专门处理

屈肘评估额外接入了肌电参与度：

```c
emg_active
```

只要某一次动作过程中出现过肌电激活，该次动作就计入肌肉参与。

总分由三部分组成：

| 分项 | 权重 |
|---|---:|
| 完成度 | 40% |
| 幅度 | 40% |
| 肌电参与度 | 20% |

训练打印：

```text
TRAIN ELBOW_FLEX rep=0/5 flex=... upper_pitch=... wrist_pitch=... max=... score=... emg=...%
```

普通状态打印在屈肘模式下保留 `flex`。

## 3. 前臂旋转 FOREARM_ROT

### 3.1 动作角度计算

前臂旋转使用腕端 `roll` 相对初始腕端 `roll` 计算：

```c
rot = abs(current_wrist_roll - forearm_zero_roll)
```

最终得到：

```c
rehab_frame.forearm_rotation_angle_x100
```

即打印中的 `rot`。

当前 `rot` 只表示旋转幅度，不区分旋前或旋后方向。

### 3.2 动作分类判定

前臂旋转使用角度和角速度共同判定。

角度触发：

```c
rot >= 15°
```

保持退出：

```c
rot >= 8°
```

角速度触发：

```c
abs(wrist_gyro_x) >= 20°/s
```

强旋转兜底：

```c
rot >= 30°
```

当 `rot >= 30°` 时，即使上臂稳定条件没有满足，也直接判为 `FOREARM_ROT`。

### 3.3 上臂稳定限制

普通前臂旋转识别会检查上臂是否稳定，避免把上臂外展、抬肩误判为前臂旋转。

当前稳定条件：

```c
abs(upper_gyro_y) < 30°/s
abs(upper_gyro_z) < 30°/s
arm_abduction_angle < 20°
shoulder_lift_angle < 20°
```

但如果满足强旋转兜底：

```c
rot >= 30°
```

则不再因为上臂稳定标志为 0 而丢掉前臂旋转。

### 3.4 评估封装

前臂旋转评估封装为：

```c
ForearmRotEval_DefaultConfig()
ForearmRotEval_Init()
ForearmRotEval_Start()
ForearmRotEval_Update()
ForearmRotEval_GetState()
ForearmRotEval_Stop()
```

默认评估参数：

| 参数 | 当前值 |
|---|---:|
| 目标次数 | 5 次 |
| 进入阈值 | 15° |
| 退出阈值 | 8° |
| 目标角度 | 60° |
| 角速度进入阈值 | 20°/s |

计数逻辑：

1. `rot >= 15°` 或 `abs(wrist_gyro_x) >= 20°/s` 时进入一次动作。
2. 动作过程中记录本次最大 `rot`。
3. 回到 `rot <= 8°`，且本次峰值至少达到 15°，才完成一次。
4. 完成 5 次后评估结束。

注意：角速度可以帮助进入动作，但单纯角速度抖动不能直接完成一次计数，最终仍要求本次峰值达到角度阈值。

### 3.5 前臂旋转专门处理

前臂旋转调试过程中加入了多项专门处理，且都限制在：

```c
#if (REHAB_ACTIVE_EVAL == REHAB_ACTIVE_EVAL_FOREARM_ROT)
```

因此只在前臂旋转评估模式下生效。

专门处理包括：

- 前臂旋转优先判定：有 `rot` 或腕端 roll 角速度迹象时，优先返回 `FOREARM_ROT`。
- 降低误判为屈肘：当前臂旋转迹象明显时，跳过屈肘分类判断。
- 降低误判为肩部上举：当前臂旋转迹象明显时，跳过 `SHOULDER_LIFT` 分类判断。
- 强旋转兜底：`rot >= 30°` 时直接判为 `FOREARM_ROT`。
- 评估侧同步兜底：`rot >= 30°` 时，评估样本也视为上臂稳定，避免出现 `action=FOREARM_ROT` 但次数不走。

训练打印：

```text
TRAIN FOREARM_ROT rep=0/5 upper_roll=... wrist_roll=... rot=... gyro=... max=... score=... stable=...
```

普通状态打印在前臂旋转模式下使用 `rot`：

```text
REHAB action=... rot=... upper_roll=... wrist_roll=... emg=...
```

## 4. 上臂外展 ARM_ABD

### 4.1 动作角度计算

上臂外展当前使用上臂端 `yaw` 相对初始 `yaw` 计算：

```c
abd = abs(current_upper_yaw - arm_abd_zero_yaw)
```

最终得到：

```c
rehab_frame.arm_abduction_angle_x100
```

即打印中的 `abd`。

同时会打印上臂 `yaw` 和 `pitch`，用于观察漂移和辅助调试。

### 4.2 动作分类判定

上臂外展有两类触发条件。

角速度触发：

```c
abs(upper_gyro_z) >= 25°/s
```

在 `ARM_ABD` 评估模式下，角度保持触发：

```c
abd >= 20°
```

保持退出条件：

```c
abd >= 18°
```

也就是说，当前上臂外展在评估模式下主要看 `upper_yaw` 相对零点变化得到的 `abd` 和上臂 `gyro_z`。退出阈值从原来的 12° 调整为 18°，让动作回落一点后就能退出保持状态，更容易完成一次计数。

在非 `ARM_ABD` 评估模式下，原有规则仍保留 `shoulder_lift_angle` 辅助条件，用于降低其他动作场景下的误判。

### 4.3 评估封装

上臂外展评估封装为：

```c
ArmAbdEval_DefaultConfig()
ArmAbdEval_Init()
ArmAbdEval_Start()
ArmAbdEval_Update()
ArmAbdEval_GetState()
ArmAbdEval_Stop()
```

默认评估参数：

| 参数 | 当前值 |
|---|---:|
| 目标次数 | 5 次 |
| 进入阈值 | 20° |
| 退出阈值 | 18° |
| 目标角度 | 90° |
| 角速度进入阈值 | 25°/s |

计数逻辑：

1. `abd >= 20°` 或 `abs(upper_gyro_z) >= 25°/s` 时进入一次动作。
2. 动作过程中记录本次最大 `abd`。
3. 回到 `abd <= 18°`，且本次峰值至少达到 20°，才完成一次。
4. 完成 5 次后评估结束。

### 4.4 上臂外展专门处理

当前 `ARM_ABD` 已经独立封装为自己的评估模块，和屈肘、前臂旋转互不复用状态。

当前活动评估已切换为：



# 双 IMU 动作识别数据说明

## 1. 佩戴坐标系

按当前佩戴方式，两个 IMU 均采用同一人体局部坐标含义：

| 轴   | 方向                 | 说明                                    |
| ---- | -------------------- | --------------------------------------- |
| X    | 沿肢体长轴，指向远端 | 上臂端指向肘/手方向，手腕端指向手指方向 |
| Y    | 指向手臂外侧         | 用于描述外侧方向的旋转轴                |
| Z    | 垂直皮肤向外         | 从皮肤表面向外                          |

陀螺仪 `gx/gy/gz` 表示绕 X/Y/Z 轴旋转的角速度，单位为 `deg/s`。正负号遵循右手定则；实际识别阶段优先使用绝对值、范围和趋势，降低佩戴方向误差影响。

## 2. 陀螺仪实际含义

### 上臂 IMU

| 数据       | 实际含义             | 主要动作                |
| ---------- | -------------------- | ----------------------- |
| `upper_gx` | 上臂绕自身长轴旋转   | 上臂内旋/外旋           |
| `upper_gy` | 上臂绕外侧轴旋转     | 肩前屈/后伸，肩上举相关 |
| `upper_gz` | 上臂绕皮肤法向轴旋转 | 手臂外展/内收           |

### 手腕/前臂 IMU

| 数据       | 实际含义             | 主要动作              |
| ---------- | -------------------- | --------------------- |
| `wrist_gx` | 前臂绕长轴旋转       | 前臂旋前/旋后，最关键 |
| `wrist_gy` | 前臂绕外侧轴旋转     | 肘关节屈伸相关        |
| `wrist_gz` | 前臂绕皮肤法向轴旋转 | 手腕偏转或水平摆动    |

## 3. 当前无线数据包

手腕端通过 HC-05 向上臂端发送 27 字节二进制帧：

| 字段              | 单位         | 用途                |
| ----------------- | ------------ | ------------------- |
| `seq`             | 递增序号     | 丢包和连续性判断    |
| `tick`            | ms           | 手腕端本地时间      |
| `acc_mg[3]`       | `g * 1000`   | 手腕加速度          |
| `gyro_dps_x10[3]` | `deg/s * 10` | 手腕角速度          |
| `angle_x100[3]`   | `deg * 100`  | 手腕 roll/pitch/yaw |
| `status`          | bit0 有效    | 手腕 IMU 是否有效   |

上臂端本地已有上臂 IMU 和 EMG，因此融合数据在上臂端完成。

## 4. 融合后的识别数据

上臂端每 100 ms 生成一帧识别数据：

```text
upper_acc_mg[3]
upper_gyro_x10[3]
upper_angle_x100[3]

wrist_acc_mg[3]
wrist_gyro_x10[3]
wrist_angle_x100[3]

elbow_angle_x100
elbow_velocity_x100_s

emg_rms_x10
emg_active
```

其中 MVP 阶段的肘角先采用基于 pitch 的相对角近似计算。系统第一次同时拿到上臂和手腕有效姿态时，会记录当时的相对 pitch 作为伸直零位：

```text
zero_relative_pitch = wrist_pitch - upper_pitch
elbow_angle = abs((wrist_pitch - upper_pitch) - zero_relative_pitch)
```

因此开机进入训练前，应让肘关节尽量伸直并保持 1 到 2 秒。后续如果需要更高精度，再改成双四元数相对姿态。

## 5. MVP 规则识别

当前先识别 4 类动作：

| 动作       | 主要依据                                                    | 辅助依据                         |
| ---------- | ----------------------------------------------------------- | -------------------------------- |
| 肘关节弯曲 | `elbow_angle` 超过保持阈值，或在 1 秒窗口内周期变化         | `elbow_velocity` 较大            |
| 前臂转动   | `abs(wrist_gx)` 明显增大，或手腕 roll 相对零位超过保持阈值  | 需要上臂相对稳定，避免外展时误判 |
| 手臂外展   | `abs(upper_gz)` 明显增大，或上臂 yaw 相对零位超过保持阈值   | 优先级高于前臂转动               |
| 肩上举     | `abs(upper_gy)` 明显增大，或上臂 pitch 相对零位超过保持阈值 | 上臂 pitch/roll 变化             |

规则法用于第一阶段演示和数据采集。调好阈值后，再考虑 1 秒窗口特征 + 轻量模型。

各动作当前都带滞回判断，保持姿态时即使角速度降为 0，也会继续识别：

| 动作       | 进入阈值 | 退出阈值 |
| ---------- | -------- | -------- |
| 肘关节弯曲 | 30 度    | 18 度    |
| 前臂转动   | 25 度    | 12 度    |
| 手臂外展   | 20 度    | 12 度    |
| 肩上举     | 20 度    | 12 度    |

调试日志中 `fore/abd/sh` 分别表示前臂旋转保持角、手臂外展保持角、肩上举保持角。

对姿态变化不明显的动作，代码还加入了动作锁存：任一动作被动态识别到后，会短暂维持约 1.5 秒。调试日志中的 `latch` 表示当前锁存的动作，用于观察例如肩上举/耸肩这类瞬时动作是否被延长显示。

前臂转动和手臂外展容易混淆时，当前规则采用“上臂证据优先”：如果上臂外展角或上臂 Z 轴角速度明显，优先判定为手臂外展；只有在上臂相对稳定时，手腕 X 轴角速度或手腕 roll 变化才判定为前臂转动。

## 6. 调试输出

上臂端 `AlgoTask` 会周期输出：

```text
REHAB action=... elbow=... vel=... range=... emg=... ugyro=... wgyro=...
```

调试时每个动作单独做 5 到 10 次，观察哪一列变化最明显，然后调整阈值。
