# AI-RehabBand 智能康复臂带 - 完整实施方案

## 📋 项目概述

**项目名称**：智能康复臂带 —— 脑卒中患者上肢运动精确评估

**核心目标**：为脑卒中患者提供AI驱动的康复动作识别和进度评估系统

**设计理念**：采用上臂+手腕双传感器方案，通过相对姿态计算实现关节角度精确测量

---

基于双STM32U575的智能康复评估与康复动作识别臂带

本作品基于双 STM32U575 同构双主控平台，面向脑卒中患者上肢康复场景，采用上臂 + 手腕双 6 轴 IMU实现肘关节角度精准解算，通过陀螺仪数据变化离线识别 6 类康复动作，以 “完成度 + 幅度 ” 指标量化康复质量。系统集成双屏显示、离线语音交互、web显示，实现训练实时反馈、数据追溯与进度评估，解决传统康复评估主观、居家训练缺乏指导的痛点，具备便携、低功耗、高隐私、高准确率（＞90%）特点，可广泛用于家庭与临床康复辅助。

## 📐 方案框架总结

### 一、系统架构

**三层架构**：

- **感知层**：上臂传感器 + 手腕传感器（双6轴IMU）
- **计算层**：上臂端（U575）+ 手腕端（U575）同构双主控
- **应用层**：两个LCD显示 + Web + 语音

**数据流**：

```
传感器 → 无线传输 → 姿态融合 → 特征提取 → AI推理 → 评分计算 → 显示/播报
```

### 三、软件架构

**上臂端任务**（FreeRTOS）：

- 传感器采集任务（100Hz）
- 无线发送任务（100Hz）
- LCD显示任务（10Hz）

**手腕端任务**（FreeRTOS）：

- 无线接收任务（100Hz）
- 姿态融合任务（100Hz）
- 特征提取任务（10Hz）
- AI推理任务（10Hz）
- 评分计算任务（10Hz）
- LCD显示任务（10Hz）
- 蓝牙发送任务（10Hz）

### 7. 运动质量评分

```c
typedef struct {
    float completion;   // 完成度 0-100
    float smoothness;   // 平稳度 0-100
    float frequency;    // 频率 0-100
    float total_score;  // 综合评分
} RehabScore_t;

// 评分计算
RehabScore_t calculateScore(int action, float* angles, int action_count) {
    RehabScore_t score;

    // 1. 完成度：实际角度 / 标准角度
    float standard_angle = getStandardAngle(action);
    float actual_angle = getMaxAngle(angles);
    score.completion = min(100, (actual_angle / standard_angle) * 100);

    // 2. 平稳度：基于角速度方差
    float gyro_variance = calculateVariance(gyro_buffer, 100);
    score.smoothness = max(0, (1 - gyro_variance / 50.0f) * 100);

    // 3. 频率：动作次数 / 标准次数
    score.frequency = min(100, (action_count / 20.0f) * 100);

    // 4. 综合评分
    score.total_score = score.completion * 0.6 +
                        score.smoothness * 0.3 +
                        score.frequency * 0.1;

    return score;
}

// 动作标准角度
float getStandardAngle(int action) {
    switch(action) {
        case ACTION_ELBOW_FLEX:    return 120.0f;  // 肘关节弯曲
        case ACTION_ARM_ABDUCTION: return 90.0f;   // 手臂外展
        case ACTION_SHOULDER_LIFT: return 150.0f;  // 肩上举
        case ACTION_WRIST_ROT:     return 90.0f;   // 腕关节旋转
        default:                   return 100.0f;
    }
}
```

## 实体按键设计补充

为保证触摸屏、App 或语音交互暂未完成时仍可独立完成训练演示，设备端增加 2 个实体按键，作为核心训练流程的本地兜底交互入口。按键采用 GPIO 上拉输入，按下为低电平，软件侧做 20-50 ms 消抖。

| 按键 | 引脚 | 电气配置 | 主要功能 |
| ---- | ---- | -------- | -------- |
| START/STOP_KEY | PA12 / USER_KEY | GPIO 输入，上拉，低电平有效 | 短按开始/暂停训练，长按停止并清零本次训练 |
| MODE_KEY | PC0 / MODE_KEY | GPIO 输入，上拉，低电平有效 | 短按切换训练动作/菜单项，长按确认或进入设置 |

按键设计原则：日常使用优先通过触摸屏、App 和语音完成交互；实体按键只承担高频、关键、可盲操作的控制动作，避免臂带上布置过多按键影响佩戴体验。
