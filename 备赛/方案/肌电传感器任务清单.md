# 肌电传感器任务清单

本文档根据 `E:\qiansai\备赛` 下的 MVP、CubeMX 配置、硬件清单、佩戴规范和论文优化建议整理，用于指导 U575 工程中肌电传感器功能实现。

## 目标定位

肌电传感器在当前 MVP 中不做医学级肌电分析，核心目标是判断患者是否主动发力，并把主动参与情况用于训练显示、评分、通信和实验验证。

当前推荐路线：

```text
单路肱二头肌 EMG
  -> ADC1 + TIM3 + DMA 采样
  -> 静息标定
  -> 整流/包络/RMS
  -> 主动发力判断
  -> 参与度评分
  -> 显示/串口摘要/训练评分
```

## 已有基础

- PB0 / ADC1_IN15 已作为 `EMG_ADC`。
- TIM3 TRGO 触发 ADC，目标采样率约 500 Hz。
- ADC DMA 环形采样缓冲区已建立。
- `EmgTask` 已能启动采样并处理半满/满缓冲。
- `emg_sensor.c` 已有 baseline、envelope、active、strength。
- 当前串口调试输出先保持不变，避免影响正在测试的数据格式。

## P0 必须完成

1. 延长静息标定
   - 训练前静息采样建议 2-3 秒。
   - 计算静息 `baseline`。
   - 计算静息噪声 `noise_level`。
   - 标定完成后再进入有效判断。

2. 完成 EMG 特征
   - 原始 ADC：`raw`
   - 电压：`voltage_mv`
   - 去基线幅值：`rectified`
   - 低通包络：`envelope`
   - RMS：建议 100-200 ms 窗口
   - 最大幅值或峰值可后续补充

3. 自动阈值
   - 优先使用静息噪声生成阈值。
   - 建议公式：`active_delta = max(default_delta, noise_level * k)`。
   - 保留手动阈值接口，便于现场调参。

4. 主动发力判断
   - `active = envelope >= active_delta`。
   - 后续可增加持续时间条件，避免瞬时噪声误触发。

5. 参与度评分
   - 输出 `participation`，范围 0-100。
   - 初版可由 `envelope / full_scale_delta` 映射。
   - 训练闭环版本应升级为有效激活时间 / 动作有效时间。

6. 新调试输出封装
   - 新增格式化函数生成 EMG 摘要字符串。
   - 暂时不替换 `StartEmgTask` 当前打印。
   - 后续可由 DebugTask、WirelessTask 或 PC 记录任务调用。

## P1 展示增强

1. 融合 IMU 判断主动/被动
   - 手臂角度变化明显且 EMG 激活：主动运动。
   - 手臂角度变化明显但 EMG 未激活：被动或辅助运动。

2. 纳入训练评分
   - 文档建议公式：

```text
总分 = 完成度 * 0.5 + 平稳度 * 0.25 + 节奏达标 * 0.1 + 主动参与度 * 0.15
```

3. 显示内容
   - EMG 状态
   - EMG 强度
   - 主动参与度
   - 主动参与次数

4. 通信摘要
   - 推荐 ASCII 摘要帧：

```text
RB,tick,action,angle,emg_env,emg_active,participation,total
```

## P2 实验验证

1. 静息 vs 主动屈肘 EMG 曲线。
2. 被动摆动 vs 主动屈肘对比。
3. 5 组重复测试。
4. CSV 字段建议：

```text
tick,angle,emg_raw,emg_mv,emg_env,emg_rms,emg_active,participation
```
